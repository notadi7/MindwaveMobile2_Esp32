Mindwave Mobile 2 – Attention Monitoring System

An ESP32-S3-based embedded system for real-time attention monitoring and visualization using the MindWave Mobile 2 EEG headset, ST7735 TFT display, and web dashboard.

Features

Real-time attention score visualization.

TFT display with system status and session information.

Web-based dashboard for session control and monitoring.

Session countdown and result display.

Wi-Fi connectivity and signal-status monitoring.

Technologies: ESP32-S3, Embedded C/C++, Arduino IDE, ST7735 TFT, Adafruit GFX, HTML, CSS, JavaScript.

Domain: Embedded Systems | Firmware Development | IoT
